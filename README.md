Aarni
=====

A small and easy to use file encryptor/decryptor.

[![aarni.png](https://i.postimg.cc/28yXnhYB/aarni.png)](https://postimg.cc/crqmSKrs)

Currently, AES-128 in the XTS mode (approved as the IEEE 1619 Standard) is used to encrypt data. SHA-384 is used to generate the encryption key and the initial tweak value from the password inputed by the user. All files are compressed before encryption.

NOTE If you forget the password you use, the only way to decrypt the file is to crack it by brutal force. So, be careful ;o

Menu position: Desktop applets
